# BitTeam by mintcandy

Независимый Android-клиент спотовой биржи BitTeam. P2P не реализован. Исходный код хранится в приватном репозитории, здесь публикуются APK и метаданные обновлений.

[Скачать последний APK](https://github.com/maxwell2010/bitteam-android-releases/releases/latest/download/bitteam.apk)

[Все версии и результаты проверок](https://github.com/maxwell2010/bitteam-android-releases/releases)

## Состояние проверки безопасности

По сообщению пользователя от 2026-11-06, текущая 0.1.9 устанавливается без предупреждений безопасности на его устройстве. Это не официальное решение Google. Ранее на этом устройстве Google Play Protect блокировал предварительные сборки. Причина прежней классификации неизвестна. Чистый отчет VirusTotal для 0.1.6 не является результатом проверки новых APK и не гарантирует снятие блокировки. Обход защиты не предлагается.

## Обновления

Постоянная ссылка выше всегда указывает на asset bitteam.apk последнего опубликованного релиза. update.json содержит версию, SHA-256, package и сертификат. Перед установкой Android проверяет совместимость подписи. Публичная тестовая линия сохраняет сертификат предыдущих сборок; это не новый production-ключ. Настройки и защищенная сессия должны сохраняться при совместимом обновлении, пока биржа принимает эту сессию.
